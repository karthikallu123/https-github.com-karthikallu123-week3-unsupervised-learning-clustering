# Week 3 - Unsupervised Learning and Clustering Analysis

This project applies unsupervised learning to the cleaned Titanic dataset used in Weeks 1 and 2.

## Methods
- Data inspection and descriptive statistics
- Feature selection and standardization
- K-Means clustering
- Elbow analysis
- Silhouette score analysis
- Hierarchical clustering with Ward linkage
- PCA-based 2D visualization
- Cluster profiling

## Selected clustering solution
K-Means with k=5 was selected as an interpretable solution in the elbow region. The silhouette score for k=5 is reported in the final report, alongside scores for other candidate k values.

## Files
- week3_clustering.py - reproducible Python analysis
- titanic_cleaned.csv - cleaned Week 1 input
- requirements.txt - Python dependencies
- charts/ - generated visualizations
- Week3_Unsupervised_Learning_and_Clustering_Analysis_Report.docx - final report
